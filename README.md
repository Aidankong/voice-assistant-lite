# 智能家居语音助手

> 轻量级本地语音助手，基于 Qwen2.5 + 自建框架

## 项目概述

这是一个完全本地部署的智能家居语音助手，用于控制通过 ROS2 连接的智能家居设备和机器人（机械臂、移动底盘等）。

### 核心特性

- ✅ **完全本地**：Qwen2.5-14B 本地运行，数据不出设备
- ✅ **轻量框架**：自建精简架构，代码量少（~500行核心代码）
- ✅ **ROS2 集成**：通过 ROS2 控制智能家居、机械臂、移动底盘
- ✅ **意图识别**：智能理解语音指令
- ✅ **工具调用**：可扩展的工具系统
- 🔄 **记忆系统**：对话记忆（待完善）
- 🔄 **语音交互**：ASR + TTS（待添加）

## 快速开始

### 环境要求

- Linux 系统（Ubuntu 推荐）
- NVIDIA GPU（推荐 8GB+ VRAM）
- Python 3.10+
- Ollama

### 安装

```bash
# 1. 克隆仓库
git clone https://github.com/YOUR_USERNAME/voice-assistant-lite.git
cd voice-assistant-lite

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动 Ollama
ollama serve

# 4. 拉取模型
ollama pull qwen2.5:14b

# 5. 测试运行
python3 quick_test.py
```

### 测试对话

```bash
# 清除代理（如果设置了）
unset http_proxy https_proxy

# 运行语音助手
python3 voice_assistant.py
```
